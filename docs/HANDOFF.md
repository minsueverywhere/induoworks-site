- `npm run build`가 테스트, 타입 검사, 빌드, CSP 해시 생성, 빌드 검증을 한 번에 실행한다.

  - 원본: `F:\music-projects\projects\Grench Boss\Sunlit Circuit\Sunlit Circuit.wav` (64초, 48kHz 24bit, SHA-256 `930fee2b…`)
  - 웹용 파일: `public/village/music/sunlit-circuit-930fee2b274e.ogg` (Opus 64k, 약 640KB)와 `.mp3` (96k, Opus를 못 쓰는 브라우저용)
  - 반복용으로 맞춘 원본이라 **페이드를 넣지 않았다.** MP3는 인코더 특성상 반복 경계에 아주 짧은 틈이 생길 수 있다.
  - 주크박스를 누를 때만 파일을 요청한다 (`src/scripts/village-music.mjs`). 초기 씬에서 음악 파일을 미리 다운로드하지 않는다.
  - 처음 재생하면 씬 오른쪽 위에 캡션·배율 표시와 같은 작은 고정폭 글씨로 곡 정보가 뜨고(평소 반투명, 마우스를 올리면 진하게), 누르면 일시정지와 재생이 바뀐다. 씬 밖의 정지 버튼과 상태 문구는 레이아웃을 밀어내서 없앴다.
  - 다시 인코딩할 때는 같은 옵션으로 `ffmpeg -i <wav> -map_metadata -1 -c:a libopus -b:a 64k -application audio <out>.ogg`를 실행한다. 원본이 바뀌면 파일명의 해시와 현재 콘텐츠 목록의 음악 정보를 함께 바꾼다.
- 소셜 채널은 Induo Works 작업실 벽면에 아이콘을 하나씩 붙여 직접 링크로 전시한다. 아이콘 이미지는 작업실에 들어갈 때 불러온다.

### 그 밖의 페이지
- 현재 홈 이름은 Induohood다. Works는 갤러리·모자이크·게시글 보기와 검색·필터를 지원하고, Workers에 Induo Works와 Frondward를 등록했다. 당시 제작자와 작품 소속은 `src/config.ts`에서 관리했으며 현재 편집 원본은 위 CONTENT.md를 따른다.
- 삼성 인터넷에서 밝은 테마가 갈색으로 보이던 현상은 사용자가 브라우저의 밝게 보기 설정으로 해결했다. 같은 기기의 Chrome에서는 정상 표시됐다. 기기별 보정색으로 사이트 팔레트를 바꾸지 않는다.

## 보류한 작업

### 로컬 편집 모드
- 목적: 화면에서 격자를 켜고 집·간판·나무·공고판을 드래그해 위치와 크기를 맞춘 뒤 저장한다. 지금은 좌표를 코드에서 숫자로 고쳐야 해서 세밀한 조정이 어렵다.
- 결론: **외부 데이터 분리 없이 만들 수 있다.** 편집 결과를 저장소의 데이터 파일(예: 배치 JSON)에 쓰고 평소처럼 빌드·배포하면 된다. 편집 모드는 `npm run dev`에서만 켜지게 하고, 공개 빌드에는 포함하지 않는다.
- 최소 범위: 격자 표시, 오브젝트 드래그, 위치·크기 조절, 저장. 집·나무의 외형은 도형 코드로 그리므로 외형 편집은 별도 도구가 필요하다.
- 시작점: 좌표는 `src/scripts/village-layout.mjs`, `content/catalog.json`의 `worker.house`, `src/scripts/village-content.mjs`의 실내 배치 목록에 있다. 먼저 이 좌표를 데이터 파일 하나로 모으는 것이 첫 단계다.

### R2·대용량 저장소
- 무료 Static Assets 기반의 런타임 분리는 위에 구현했다. R2 가입·과금 서비스 전환과 관리자 화면은 여전히 보류이며 [이슈 #2](https://github.com/minsueverywhere/induoworks-site/issues/2)에 남긴다.
- R2 요금 비교는 이슈의 과거 후보 검토다. 현재 정적 콘텐츠 요청에는 R2 읽기 요금이 생기지 않는다.
- 로컬 배치 편집 모드의 선행 조건으로 R2를 삼지 않는다.
